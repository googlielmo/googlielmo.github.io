Function etc_diag_type_ref_failure

1

func etc_diag_type_ref_failure(self: ExpressionTypeChecker*, tref: TypeRef*, fallback_code: string, span: Span)

Emit the most specific diagnostic for a failed type-reference resolution.

Special cases preserve shared diagnostic codes for nullable void , ambiguous names, unresolved aliases, and value symbols used as types. Other failures use fallback_code so callers can keep context-specific unknown-type codes.

Parameters:

  • self: Expression checker state.
  • tref: Type reference that failed to resolve.
  • fallback_code: Diagnostic code for generic unknown-type failures.
  • span: Source span to report for diagnostics.
