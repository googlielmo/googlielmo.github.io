Function etc_scope_chain_push

1

func etc_scope_chain_push(self: ExpressionTypeChecker*, target: Scope*) -> int

Activate every missing lexical scope from the tracked scope to target .

Synthetic single-statement scopes can sit between the currently active scope and a mapped loop or with header scope, so each ancestor must have its own declaration and liveness state.

Returns: Number of scope states pushed.
